## Unreleased

### Added

- §6.5 IPC control channel: `\\.\pipe\io.github.slc.Control` on Windows
  (`--ctl RELOAD|STATUS|SETCONFIG <json>`) and `io.github.slc.Control`
  D-Bus adaptor on Linux; shared `ScreensaverApp::controlCommand`
  dispatch with a per-second JSON status snapshot
- CI: Debug builds (dev-* presets) alongside Release on all 3 OSes,
  advisory clang-tidy job, gcovr coverage job, per-OS smoke job,
  Xvfb/llvmpipe visual-regression job
- §9.4 visual regression: `slc_visual` harness renders a seeded
  collage to FBO → PNG; `--compare` vs committed goldens
  (`tests/visual/golden/`) with tolerance for rasterizer variance

### Fixed

- clang-tidy gate findings in core: implicit widening in file-size
  limits (logging/appinfo_names/steam_locator), a cloned conditional
  branch in config seed parsing, and silent empty catches in
  hltb/steamgriddb/steam_locator — now logged at debug level
- §6.1.3 Path C: `ext-idle-notify-v1` idle watcher on Wayland
  (compositor-negotiated, DBus fallback); honors idle inhibitors
- §6.2 OS keychain for the SGDB key: Credential Manager (win),
  secret-tool/libsecret (linux), Security framework (mac); env var
  still takes precedence; `--store-sgdb-key` on both hosts
- macOS wallpaper backend (`NSWorkspace` setDesktopImageURL on every
  screen) — completes §6.1.4; compile-only until validated on a Mac
- CI: clang-tidy now hard-gates PR-changed files on
  bugprone-*/clang-analyzer-*; coverage floor `--fail-under-line 40`;
  `smoke-desktop` self-hosted scaffold (repo var `SLC_SELF_HOSTED_SMOKE`)
- Optional ImGui debug overlay (`SLC_WITH_IMGUI`, `--debug-ui` or
  `advanced.debugUi`): FPS/frame-time, scene + decode-pipeline stats,
  live badges/blur/collage-animation toggles; text overlay remains as
  fallback in non-ImGui builds
- Integration tests (`tests/integration`): fixture → content → layout →
  choreography pipeline, seeded determinism, exclusion flow
- Google Benchmark suite (`tests/bench`): layout strategies, VDF/config
  parsing, artwork pick
- Docs: `docs/USER_GUIDE.md`, `docs/DEVELOPER_GUIDE.md`,
  `docs/SPEC_STATUS.md` living spec-conformance table, `docs/adr/`
  scaffold + ADR-0001, `Doxyfile` + CI docs job
- `cliff.toml` git-cliff config

### Changed

- `SLC_TEST_*` env hooks are now gated behind `--allow-test-hooks` on all
  hosts; the flag is forwarded to sessions spawned by the Linux daemon

### Fixed

- CI `push` trigger now listens on `develop` (repository trunk), not `main`
- Removed a stray `#ifdef _WIN32` in core (`badgeDate` now uses portable
  `std::localtime`) restoring core isolation

### Features

- Screensaver + live-wallpaper core: Cinder GL renderer, 7 collage
  strategies, Ken Burns, collage choreography, scene transitions
- Steam discovery: appinfo/libraryfolders/loginusers/localconfig parsing,
  user grid-art precedence, achievement + playtime stats
- Badges: title, playtime/last played, HLTB, achievement completion
- Optional enrichment: SteamGridDB (env-keyed, cached, rate-limited),
  HLTB background resolution
- Qt configurator + tray with wallpaper-mode switching
- Windows `.scr` host (full `/s` `/c` `/p` `/a` contract, WorkerW
  live-wallpaper embedding), Linux DBus/XSS/layer-shell hosts, macOS
  `.saver` bundle
- `slc_wallpaperd` static-wallpaper daemon (Win/Linux backends)

### Documentation

- README, user + developer guides, AGENTS.md, SPEC_STATUS.md,
  ADR scaffold
